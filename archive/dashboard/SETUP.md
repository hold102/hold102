# Archived profile dashboard

The old profile and its generator are preserved in this folder. To update the live profile, edit the [main README](../../README.md) directly.

To rebuild this archive from its saved data, run the following command from the repository root.

```sh
node archive/dashboard/scripts/build.mjs --offline
```

The command writes the preview and its images inside this folder. The former daily refresh workflow is archived here as well.
